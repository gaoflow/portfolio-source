Methods

  • Finite Biot-Savart segments assembled into one-row horseshoe-vortex lattices.
  • Reversed image vortices enforce a moving ground plane without a viscous road boundary layer.
  • Ride-height sweep, Trefftz-plane induced drag, analytical scale check, and span refinement.

Reproduce

  • cd projects/ground-effect-vlm && python3 -m unittest discover -s tests -v
  • cd projects/ground-effect-vlm && python3 scripts/analyse.py
  • cd projects/ground-effect-vlm && python3 scripts/build_demo.py

Limitations

  • The model is linear, inviscid, steady, incompressible, and zero-thickness.
  • There are no tyres, body, diffuser, leakage, separation, or moving-road boundary layer.
  • The published sweep stops at quarter-chord height h/c=0.25 and is not a race-car performance prediction.
