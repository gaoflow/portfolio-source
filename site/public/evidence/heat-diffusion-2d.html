Methods

  • Cell-centred finite-volume FTCS on a uniform square grid with Dirichlet and zero-flux Neumann boundaries.
  • Hard stability gate: runs with r = alpha*dt/dx^2 > 0.25 are refused and logged before integration.
  • Quasi-1-D validation against the analytical slab series truncated at a 1e-14 envelope tolerance.
  • Temporal order isolated by refinement against a fine-time reference on a fixed grid.

Reproduce

  • cd projects/heat-diffusion-2d && python3 -m unittest discover -s tests -v
  • cd projects/heat-diffusion-2d && python3 scripts/analyse.py
  • cd projects/heat-diffusion-2d && python3 scripts/publish_site.py

Limitations

  • Explicit scheme: the stability bound forces dt to shrink with dx^2.
  • Constant isotropic diffusivity; no advection, sources, or phase change.
  • Cartesian uniform grids with square cells only.
  • First order in time, second order in space; the temporal-order check uses a fine-time reference because the analytical error couples space and time truncation.
