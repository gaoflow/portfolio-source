Methods

  • D2Q9 BGK collision with halfway bounce-back walls and moving-wall momentum correction.
  • Three-grid convergence study at Reynolds number 100.
  • Centerline interpolation against Ghia, Ghia and Shin reference values.

Reproduce

  • cd projects/flowlab && npm test
  • cd projects/flowlab && npm run validate
  • cd projects/flowlab && npm run build:report
  • cd projects/flowlab && npm run publish:site

Limitations

  • Two-dimensional single-relaxation-time lattice model on coarse grids.
  • Validation covers one Reynolds number and one canonical internal-flow geometry.
  • Browser speed and lattice time are not physical vehicle-flow predictions.
