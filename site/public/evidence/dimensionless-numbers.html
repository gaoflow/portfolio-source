Methods

  • Defining equations implemented in expanded form so the Ra = Gr * Pr identity is a genuine check.
  • SI dimension-vector guards reject dimensionally inconsistent or non-physical inputs with explicit errors.
  • Property table: piecewise-linear lookup, exact at anchors transcribed from Incropera 7th ed. Tables A.4/A.6.

Reproduce

  • cd projects/dimensionless-numbers && python3 -m unittest discover -s tests -v
  • cd projects/dimensionless-numbers && python3 scripts/analyse.py
  • cd projects/dimensionless-numbers && python3 scripts/publish_site.py

Limitations

  • Constant-property table: five anchors for air and water, linear interpolation, no extrapolation.
  • Incompressible-regime scope; no real-gas effects beyond the perfect-gas speed of sound.
  • Regime-limit annotations in the sweep figure are intuition, not transition predictions.
