Methods

  • Complex-potential elementary flows (uniform, source/sink, doublet, vortex) with dW/dz = u - iv.
  • Superposed flow past a circular cylinder with imposed circulation, positive clockwise.
  • Fixed-step RK4 streamline tracing checked against the analytical streamfunction Im(W).

Reproduce

  • cd projects/potential-flow-sandbox && python3 -m unittest discover -s tests -v
  • cd projects/potential-flow-sandbox && python3 scripts/analyse.py
  • cd projects/potential-flow-sandbox && python3 scripts/publish_site.py

Limitations

  • Inviscid, irrotational, incompressible, and strictly two-dimensional: no boundary layer, separation, or wake.
  • Circulation is imposed, not predicted; no Kutta condition selects it.
  • Zero drag is a property of the model class (d'Alembert), not a prediction.
