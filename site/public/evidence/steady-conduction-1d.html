Steady 1-D conduction with finite differences

The first discretised PDE in the study sequence: a generating rod with a convective tip, solved with a from-scratch Thomas algorithm and verified against closed-form and manufactured solutions.

Methods

  • Node-centred finite differences with a half-control-volume Robin tip.
  • Thomas algorithm implemented from scratch for the tridiagonal solve.
  • Closed-form exact solution, manufactured-solution grid-convergence study, and conservative global energy balance.

Reproduce

  • cd projects/steady-conduction-1d && python3 -m unittest discover -s tests -v
  • cd projects/steady-conduction-1d && python3 scripts/analyse.py
  • cd projects/steady-conduction-1d && python3 scripts/publish_site.py

Limitations

  • One-dimensional, steady state with constant thermal properties.
  • No contact resistance at either boundary; tip radiation is excluded.
  • The quadratic physical solution is reproduced to roundoff, so the convergence order is demonstrated on a manufactured source term.
