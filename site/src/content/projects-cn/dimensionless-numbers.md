## 我为什么先做这个小工具

刚开始学流体力学和 CFD 的时候，我发现很多估算都要从无量纲数算起。雷诺数告诉我面对的是哪种尺度的流动，马赫数帮我判断要不要考虑压缩性，普朗特数、努塞尔数、格拉晓夫数和瑞利数则会出现在传热和自然对流的问题里。

公式都不长，真正容易错的是往里填的数。举个例子：动力黏度和运动黏度只差一个密度的关系，但单位和数值完全不一样。要是把两个搞混，计算器照样会吐出一个看着挺正常的雷诺数，可后面的网格划分、相似性判断、求解器设置全会跟着错。

所以我没有直接写一堆只吃浮点数的公式，而是先做了这套会检查单位、数值范围和物性来源的工具。

## 这套工具能算哪六个数

| 无量纲数 | 定义 |
|---|---|
| 雷诺数 | $Re=\rho uL/\mu$ |
| 马赫数 | $Ma=u/a$ |
| 普朗特数 | $Pr=\mu c_p/k$ |
| 努塞尔数 | $Nu=hL/k$ |
| 格拉晓夫数 | $Gr=g\beta\lvert\Delta T\rvert L^3\rho^2/\mu^2$ |
| 瑞利数 | 用展开后的定义单独计算 |

普通浮点数一律当成 SI 单位。想查得更严，可以传入带单位的 `Quantity(value, unit)`。工具会核对质量、长度、时间和温度的量纲对不对得上公式，还会拦下零值、负值、无穷值和超出物性表范围的输入。

## 我最想防住的是单位混用

动力黏度 $\mu$ 的量纲是 $ML^{-1}T^{-1}$，运动黏度 $\nu$ 的量纲是 $L^2T^{-1}$。这俩根本不是一个物理量。

我要是把运动黏度塞到动力黏度的位置上，工具不会接着算，而是直接告诉我：哪个参数错了、本来该是什么量纲、实际收到的又是什么单位。

其他几种常见错也照拦：

| 输入出了什么问题 | 为什么要拦 |
|---|---|
| 把运动黏度 $\nu$ 当成动力黏度 $\mu$ | 差了一个密度关系，不是一个物理量 |
| 绝对温度不大于零 | 理想气体关系 $\beta=1/T$ 没法定义 |
| 特征长度是零 | Re、Nu 和 Gr 就没有物理尺度了 |
| 查物性查到了表格外 | 插值就没有来源撑腰了 |

## 物性数据是从哪儿来的

我从 Incropera 第 7 版的表 A.4 和表 A.6 里转录了空气在 300–400 K、水在 300–320 K 范围内的五个锚点，又拿 NIST Chemistry WebBook 交叉核对了一遍。

查询落在锚点之间就用分段线性插值；落在范围外就直接拒绝，不外推。表里的普朗特数还会跟转录的 $\mu$、$c_p$ 和 $k$ 重新算一遍对账，两边在 0.19% 以内一致。

这张表没想覆盖所有流体，只是先给常见的空气和水问题准备一组来源清楚、范围明确的输入。

## 一个测试得真的有可能失败才行

瑞利数满足 $Ra=Gr\cdot Pr$。一开始我完全可以偷懒，让 `rayleigh()` 直接返回 `grashof()*prandtl()`，这样两边永远相等，测试误差永远是零。

可这种测试只是拿一个表达式跟它自己比。就算 Gr 和 Pr 的实现共享同一个错误，测试照样通过。

所以我用展开后的定义单独实现了 Ra，再分别算 Gr 和 Pr。然后在 500 组固定随机种子的样本上比对这两条计算路线，最差相对误差是 $4.4\times10^{-16}$。到这一步，这项检查才真正有能力抓出错误。

## 我留下来的检查结果

| 检查内容 | 结果 | 要求 |
|---|---:|---:|
| 参考 Re 和手工计算对比 | 相对误差 0.0 | $\leq 10^{-12}$ |
| $Ra=Gr\cdot Pr$，500 组样本 | $4.4\times10^{-16}$ | $\leq 10^{-12}$ |
| 无效输入被拦下 | 10/10 | 10/10 |
| 物性锚点精确匹配 | 20/20 | 20/20 |

一个能手算核对的例子是：

$$
Re=\frac{1.225\times15\times0.3}{1.81\times10^{-5}}\approx3.05\times10^5.
$$

在同样的海平面物性下，5 m 整车尺度在 60 m/s 时能到 $Re=2.03\times10^7$。头图把三个 FSAE 特征长度对应的 $Re(u)$ 画在同一张对数坐标图里，一眼就能看出速度和特征长度是怎么一起改变流动尺度的。

图里的 $5\times10^5$ 和 $10^7$ 只是教材层面的流态参考。真实的转捩还受表面粗糙度、压力梯度和自由来流湍流度影响，光凭一个雷诺数说了不算。

## 这套工具还干不了什么

目前物性表只有五个锚点，只覆盖空气和水，插值也是线性的。空气的体积膨胀系数用的是理想气体关系 $\beta=1/T$。

这套工具主要面向不可压缩流动。它能算马赫数和完全气体声速，但不包含真实气体效应，也代替不了转捩、粗糙度、湍流或传热模型。

## 这个小项目教会我什么

这套工具最重要的部分不是那六个公式，而是它能拒绝错误输入。我自己手算时反反复复在黏度和单位上栽跟头，所以我先把“出错时怎么办”这条路设计好，再去设计正常计算的路。

它还让我养成了之后一直用的习惯：检查程序不能只证明它能跑，还得故意喂错误输入，确认它会在正确的位置停下来。

## 代码与运行

代码已开源在 GitHub：[gaoflow/dimensionless-numbers](https://github.com/gaoflow/dimensionless-numbers)

```bash
git clone https://github.com/gaoflow/dimensionless-numbers.git
cd dimensionless-numbers
python3 -m unittest discover -s tests -v
python3 scripts/analyse.py
PYTHONPATH=src python3 -m dimensionless_numbers reynolds --rho 1.225 --u 50 --l 1.0 --mu 1.81e-5 --json
```
